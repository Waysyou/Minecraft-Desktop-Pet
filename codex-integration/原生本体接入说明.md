## Qoder 接入（2026-10-28）

- Qoder Desktop 通过用户级 hooks 接入：`%USERPROFILE%\.qoder-cn\settings.json` 的 UserPromptSubmit、PreToolUse、PostToolUse、PostToolUseFailure、PermissionRequest、Stop、StopFailure、SessionEnd 均调用本目录 `QoderEventRelay.exe --hook`。
- 转发器只读取 `session_id`、`hook_event_name`、`tool_name`、`cwd` 并取工作区文件夹名，消息标记 `source=qoder`；不转发或保存提示词、工具参数、结果、转录正文和凭据。源码为 `QoderEventRelay.cs`，用量读取为 `QoderUsage.cs`。
- 联动器新增 Qoder 进程识别：Qoder 运行时即使 Codex 未运行也会显示气泡；任务行显示“Qoder · 工作区 · 会话末六位”。Qoder 的 AskUserQuestion、ExitPlanMode 和权限请求显示为等待输入。
- Qoder 本地只记录 Credits 和上下文占用，不提供 token 数或缓存命中。气泡显示 `Qoder · 今日 Credits … · 上下文 …`；主任务是 Qoder 时显示 `Qoder 本轮 … Credits · …/分`，并明确标注“Qoder 未提供 token 速度/缓存”。Credits/分钟按本轮墙钟时间计算，口径类似 Codex 的均速，但单位是 Credits。
- 今日 Credits 和本轮 Credits 使用本目录 `qoder-usage-index.json` 账本持久化，仅保存 request id、session id、时间、Credits 和上下文百分比，不保存聊天内容；这样 Qoder 压缩 transcript 或联动器重启后数字不会倒退。账本启用前已被压缩的历史可能少计，准确额度以 Qoder 官方用量页为准。
- Codex 的每日 token、五小时/一周额度、本轮均速和缓存仍来自 Codex 本地用量事件。按“只显示精确值”的选择，Qoder 不折算进 token 总数，气泡里的 `Codex · 今日 token` 是 Codex 单独的量。
- 会话结束由 Qoder 的 Stop/SessionEnd 事件移除；未收到结束事件时沿用原规则保留，超过十五分钟标注无新事件。

## V3.4 每日 token 活动

- 在额度下方增加每日 token 数值，不增加托盘图标或常驻窗口。来源和更新时间说明行已在 V3.6 删除，气泡显隐与人物透明度规则不变。
- 优先通过当前已登录 Codex CLI 的 `account/usage/read` 读取 `dailyUsageBuckets`，约每 10 分钟刷新。显示官方桶的日期；官方文档未明确日期时区，不另行转换桶日期或拼成重置历史。
- 官方数据取不到、缺少当天桶或缓存超过 15 分钟时，使用本机统计。读取 `CODEX_HOME`（未设置则用户目录 `.codex`）下 `sessions` 和 `archived_sessions` 的用量元数据，约每 2 秒增量刷新。跨天按本机时区切换；来源可在 `status.json` 的 `dailyTokens.source` 查看。
- 本机值是日志里累计输入加输出 token 的增量，包含缓存输入；不把缓存输入、推理输出等子项重复相加。重复累计值跳过，复制的相同事件去重，文件开始的继承累计数仅采用最后一次请求量。日志缺失、截断、未上报或不同设备/账户活动会让本机值与官方不同。
- 无数据时显示未知/读取中，不把官方缺失桶当成 0。本机记录目录存在而当天确实没有记录时可显示 0。
- 索引 `daily-token-index.json` 保存在本目录 G 盘，仅含读取位置、会话/轮次标识、开始时间、事件身份散列、日期和计数，不保存聊天正文。仅保留最近七天的事件计数索引以支持去重，文件游标用于重启续算。
- token 数不是五小时或每周额度的百分比，也不是账单金额。

## V3.5 输出均速与缓存

- 对应气泡最上方那条任务，以真实 hook 的会话 ID 和轮次 ID 匹配本地 `task_started`、`token_count` 元数据；多个对话之间不合并这些指标。
- “本轮均速约” = 本轮累计输出 token / 从本轮开始到当前的秒数。输出采用累计 `output_tokens` 的增量，不将 `reasoning_output_tokens` 再相加。分母包含工具执行、网络及等待时间，因此不是模型流式解码速度；没有逐 token 时间戳时不提供伪精确的瞬时速度。
- 旁边显示本轮输出 token；“最近请求缓存”显示最近一次有新用量的模型请求：缓存输入 token / 输入 token，以及两者比例。输入和输出不混作缓存比例的分母。
- 用量日志约每 2 秒采样，均速界面每秒更新。它在新用量落盘后更新，不是尚未完成请求的逐 token 计数。
- 缺少本轮记录、开始时间、输出或缓存字段时显示 `--`，不套用上一轮数据。真实零命中显示 0%；输入为 0 或缓存数大于输入数时比例未知。长时间没有新样本会注明上次记录时间。
- 索引升级为版本 2，首次重建只扫描/解析用量与任务开始元数据，不解析或保存聊天正文；后续按文件游标增量读取。没有新增字节时不反复写缓存。

- 开始调用工具：正在调用工具。
- 收到权限请求或输入提问事件：等待你的输入或确认；后续工具活动或新输入会继续更新状态。
- 本轮回复结束、停止或中断：该任务从气泡移除。
- 有多个会话运行时，最多显示最近更新的三个，超过三个显示额外数量。一个会话结束不会盖掉其他运行中的会话。
- 没有运行中的会话时，气泡立即消失；有其他会话仍在运行时继续显示它们。
- Codex 退出，或原版桌宠隐藏/退出时，气泡隐藏。关闭 Codex 后会清除本次记录，避免下次启动显示旧任务。
- 长时间没有新事件时，不擅自把任务标记为完成；超过十五分钟会注明“分钟无新事件”。

接口能识别运行中的会话，不能识别当前选中的聊天标签。气泡按会话显示，用“工作区文件夹名 · 会话编号末六位”区分。它不是聊天标题，也不会读取或总结聊天正文。

## 五小时与一周额度

- 显示的是账户剩余比例，不是剩余 token 数或当前会话上下文。
- 每二十秒检查 Codex 本地最新用量事件，只解析 token_count 记录里的 rate_limits 元数据，不提取或保存聊天正文。
- 五小时窗口按 300 分钟识别，一周窗口按 10080 分钟识别，使用率转换成剩余比例；两种窗口缺失时分别显示“未知”。
- 同时显示记录更新时间和各窗口的重置时间。超过十分钟没有新用量事件会标记“上次记录”；重置时间已过时显示“待刷新”，不擅自填入 100%。
- 额度随 Codex 新用量事件更新；关闭或长时间闲置 Codex、在其他设备使用账户时，本机不会凭空得到新数据，请看更新时间。
- 读取现有 C 盘 Codex 会话日志的有限尾部，不复制日志；程序、测试、编译工具、缓存和模型源码均放在 G 盘。
